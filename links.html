UltraPlayer - リンク一覧

よく使うページをここからまとめて開けます。main.py と bgm-library の起動が必要です。

操作者用

control.html - 管理画面
再生操作・音量・プレイリスト・次第の進行・配信画面の位置調整
bgm-library - 曲のアップロード/管理
音源アップロード・YouTubeダウンロード・作者検索・次第へのBGM割り当て
http://127.0.0.1:4000

配信用 (OBSのBrowser Sourceに追加)

monitor1.html - モニター1 (左)
monitor2.html - モニター2 (右)
display.html
⚠ 単体配信用。monitor1/2.html と併用しないこと

ローカルAPI (main.py, ポート8787)

GET /now-playing - 配信画面向けの現在状態
GET /admin/status - 管理画面向けの詳細状態(音量・プレイリスト・次第)
POST /command - 再生操作 {"command": "PLAY_PAUSE"|"STOP"|"NEXT"|"PREV"|"VOL_UP"|"VOL_DOWN"}
POST /program/advance - 次第を次の演目へ進める
POST /program/back - 直前の進行を1つ取り消す
GET/POST /calib - 配信画面のキャリブレーション状態

このページ自体、control.html・monitor1/2.html・display.html は main.py の APIサーバーから配信されます。python main.py --dir ./tracks を実行した状態で http://127.0.0.1:8787/links.html(ポートは --api-port で変更可) を開いてください(file:// 直開きだと fetch がブロックされる環境があります)。 同じルーター配下の他端末からは http://(このPCのLAN内IP):8787/links.html でアクセスできます。 bgm-library は別プロセス(cd bgm-library && npm start)で起動します。
